## 1. 这是什么

宋代市井题材的城建经营模拟游戏，HTML5 网页版。机制参照《满庭芳·宋上繁华》（建造 + 资源链 + 人口/繁荣度），**美术、文案、建筑名、数值全部原创**，仅借鉴机制思路。当前为灰盒色块阶段，无正式美术。

### 1.1 已实现功能（灰盒）

- 32×32 网格地图（含沃土/林地地形约束），相机缩放/平移
- 9 种建筑，4 级繁荣度阶梯解锁，**Lv4 即竖切片通关点**
- 双资源链自动流转：粮线（农田→磨坊→食肆→铜钱）、木线（林场→木匠铺→杂货摊→铜钱）
- 人口：空房 + 食库存 >10 每 5 tick 迁入 1 户；食耗尽迁出（保底 1 户）；工坊商铺占劳力
- 市税：每户每 tick +0.05 铜钱（v0.3 新增，防资金死锁的保底收入）
- 断链警示（缺料红 / 缺人黄）；HUD 显示资源、人口、市税与商业收入拆分、繁荣度进度条
- 暂停 / 1× / 2× 变速；localStorage 最小存档（每 30 tick 自动 + 手动按钮）
- 游戏内遥测采集 + 通关导出面板（`src/core/telemetry.js` / `src/ui/telemetryPanel.js`）→ `playtest-session-<时间戳>.json`

```bash

npm run dev        # 开发试玩 → http://localhost:5173（⚠ 试玩前必重启，见 §5.3）
```

## 附录A 已知非阻断问题

- **浮点尾差**：铜钱 float 累计，最坏路径回血比理论值多 1 tick（49.999… 尾差）。若介意可改内部存「厘」（整数分），需设计侧拍板。
- **食肆抢劳力边缘**：人口=1 时先放食肆会抢磨坊劳力致其空转，玩家可拆除恢复；食链优先结算已缓解，未完全杜绝。
- **恒计分残余口子（设计红线级）**：农田/林场/粮仓不占劳力、不吃产业链、恒计分。真人第 4 局 farm10+forest8+granary2 = 40 分白送（占 Lv4 的 40%）。02 文档「全图约可建 20~25 座原料建筑」属**事实错误**（实为农田 132 / 林场 128 锚点）。封顶 26 已把占比压到 17.8%。
- **粮仓刷分**：实测仅占 6.6%，按 D3 挂观测（改它 L\* +16% 会越带）。

## 附录B 纪律备忘（给下一位接手者）

1. **数值改动必须过验收推演**：改 config 后必跑 `tests/verification/progression.test.js` 的 bot 通关推演 + V1 注入铜钱用例。别信纸面。
2. **验收与开发自测分离**：`tests/verification/` 是独立基准，开发者不许改它来让自己的代码通过。若需改 bot，必须走用户授权 + 新旧并行 + 先复现基线三条约束。
3. **版权红线**：只借鉴机制，文案/名称/数值全原创，不引入《宋上繁华》任何资产。
4. **core 是规则唯一权威**：任何玩法判定落在 `core/`，UI 只做展示层。
5. **V1 Gate 余量口径**：现行最紧的是 **O6′（封顶26+145）的 V1 余量 0.74 分**（145.74−145），勿与 cap28+145 的 2.74 混淆。任何「削恒计分」类改动都会动 V1 边界，动分值前必看 `03-pacing-postmortem-round2.md` 附 2 §1b 边界表 + `scratch/pacing-sim12.mjs` 矩阵。
6. **配置基线快照（D10）**：`tests/config.test.js` pin 的是**现网值**——实施改数值时此测试**会红，这是设计目的**：逼着人走「确认是有意调整」流程更新快照。封顶值实施时必须同步入快照。
7. **遥测不要信看起来合法的假值**：一个看起来像真 commit 的兜底值比明显的错误值危险得多。任何降级/兜底值必须一眼可辨为不可用。
8. **判定纪律**：pace 判定为 advisory，最终动数值由用户拍板；判定组必须含不同玩家（同一人多局只反映学习效应）。
9. **L\* 读数纪律**：爬山搜索有构型盲区（大城/小城/工厂镇三吸引子，种子敏感 ±200%），L\* 一律视为**该搜索预算下的上界**，不得单独作落带判据；落带以真人试玩为主、多构型种子枚举为辅。引用工厂镇读数必须标注 N=∞/N=1。
10. **决策级结论必须独立复核**：任何将改变用户决策方向的读数，先由第二成员独立 harness 复放再呈报。
11. **bot 口径换算纪律**：任何 bot↔真人换算系数必须标注 bot 口径与基线版本（旧 515 / 新 480）；跨版本对比必须显式注明。
12. **观测量 ≠ 约束力（tick 末 ≠ tick 内）**：「tick 末粮库存=0」否定不了「tick 内被截断」（农田逐座 addResource 时即被 `Math.min` 截断，峰值 44）。断言「某约束不生效」前，必须确认看的是约束施加那一刻。
13. **近似/搜索/补丁产出的数只能判方向**：引用必须连带档位标签（准实现 blob / 结构近似 scale / 规则级近似 D-N2-7 外层补丁），禁止裸引数字。
14. **噪声带判定必须双向对称**：落在噪声带（0.3~0.9pp）内的信号既不能冒充改善、也不能充当恶化证据；承重证据必须是结构/构成级离散变化；改善阈值（−12pp）必须高于噪声带。
