## 2. D 候选专项：题材自洽性论证（调研结论）

纸艺不只是"画风选择"，对本案是**历史媒介选择**：

- **剪纸艺术盛于宋代**：宋代造纸业成熟 + 市民文化繁荣，剪纸从"宫廷雅艺"变为"人间烟火"——与游戏题材时代完全重合；
- 《武林旧事》载汴京盛行"剪字""剪镞花样"行业，剪纸艺人**俞敬之在瓦子现场剪纸售卖**——瓦子正是宋代市井核心场景；
- 宋代纸艺应用现成素材库：窗花、灯花、走马灯、纸影戏、纸扎彩楼（乞巧节"仙楼"）——UI、动画、彩蛋皆可取材，**与游戏内容系统（未来节日/市集玩法）有共振空间**；
- 先例参考：Paper Mario（立体书分层 + 交互态兼容已验证）、Papetura（实物纸模路线天花板，但 1 人 4 年工期——**此路线排除**，只走数字矢量模拟）、Paper Trail / 国产《纸片少女》（商业化先例）。

## 3. 推荐方案：**B 与 D 并列优选，样张对比后拍板**（A 降为包装层借调）

- **A 出局游戏层**（不变）：32×32 tile 上晕染糊成色块，警示态撕裂画面——花了 A 的成本得到 C 的效果。
- **C 出局**（不变）：不解决空转时段「无可看之物」的体验缺口。
- **B vs D 是真正的决赛**：
  - 选 **B** 的理由：成本与警示态兼容性最确定，网格可读性满分，工期最短。
  - 选 **D** 的理由：题材自洽性（§2）+ 差异化最强 + 情绪价值最高；样张已证硬边可读性优于水墨，仅剩「俯视缩样终验」一个风险点。
  - 我的倾向：**D**——美术先行决策的理由①就是补"体验/情绪缺口"，D 在情绪维度收益最大，且历史媒介自洽是不可复制的卖点；代价是多一道 32×32 缩样验证。
- **包装层策略与游戏层解耦**：HUD 边框/标题/通关面板可按最终方向借调（B 配水墨元素 / D 配剪纸红窗花纹样），不随游戏层二选一。

## 4. 落地路径（拍板后执行，两方向共用骨架）

1. **资产制作**：以对应样张为风格锚点，产出 9 建筑 ×（1×1/2×2 两档）+ 3 地形 tile；AI 出稿 + 人工修。B 需统一调色板与像素网格；D 需统一纸层数（≤3 层）、投影方向与纸纹理。
2. **（D 专属前置）32×32 缩样终验**：把样张建筑缩到实机 tile 尺寸目检区分度，通过才全面投产。
3. **代码改造**：仅动 `src/render/renderer.js`（色块 → sprite 绘制）与 `src/config/buildings.js` 旁挂 `sprite` 字段（**数值字段一行不动，不破 D-C1**）；相机缩放启用 nearest-neighbor（B）/ 平滑缩放（D）。
4. **验收**：`npm run test` 142 用例全绿（render 层无逻辑断言，预期零回归）+ 目检断链警示/选中态可见性。
5. **工期估计**：B = 资产 2~3 天 + 接入 0.5 天；D = 缩样验证 0.5 天 + 资产 3~4 天 + 接入 0.5 天。均可与 A4-d 复测并行（互不阻塞）。
