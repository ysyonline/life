## 4. 核心发现一：新手 Lv2→Lv3 停滞（G1，D4 教学检查点抓到真问题）

G1 在 tick 47 到达 Lv2 后，**停滞了 220 tick（3.7 分钟）才到 Lv3**（tick 267）：

- tick 90~240 繁荣度几乎不动：27 → 28 → 28 → 30.5 → 33 → 43（150 tick 仅 +16）
- 玩家行为：**建房优先**——tick 180 已建 hut 11（住房容量 22），但农田/林场/磨坊维持 3/3/2，**完全不建食肆与商业**；木材堆积到 473（无木匠铺）
- 破局时刻：tick ~240 建起 eatery 2 → 繁荣度重新开始爬升 → 此后一路加速（43→52→65→77→103→…→148）
- 机理：P2（民居按入住率计分）+ 恒计分封顶 26 生效后，「狂建茅舍」不再刷分，新手失去方向时没有引导告诉 TA「下一步是商业」

**⇒ 这是 D4「Lv2 = 教学检查点」设计意图的第一次实战验证：它抓到的不是节奏问题，是引导缺口。** 建议立项 UX 候选「Lv2→Lv3 新手引导」（如：停滞 N tick 后提示「食肆可将粮食转为铜钱」），入 §6.4 P2 候选池（advisory，用户拍板）。

## 5. 核心发现二：M9′ 空转占比镜像反转——「空转是熟练玩家问题」实证

| 玩家 | 局 | M9′（空转帧占比） | 稀缺帧构成 |
|---|---|---|---|
| bot @ O6′ | V2 基线 | 82.3% | 缺料 0 / 缺人 0 |
| P1（熟练） | 第 5 局 | 80.7% | 危机段外零稀缺 |
| **P2（新手）** | **G1** | **52.0%** | 缺料 222 + 缺人 69（tick 269~502 长期危机） |
| **P2（新手）** | **G2** | **44.1%** | 缺料 148 + 缺人 150（磨坊过剩致粮荒持续 205~332） |

- 新手两局全程大半时间在「救火」（缺料/缺人），**空转对新手根本不存在**；空转集中在熟练玩家（规划好 → 无 scarcity → 等节拍）。
- ⇒ 与 N2 立项时的判断（「空转与玩家水平正相关」，第 3 局 100% vs 第 4 局 0%）完全互洽，**D-N2-7/8 暂缓的决策被新数据再次加固**：N2 治的是熟练玩家体验，新手侧的问题在引导（§4）而非空转。
- ⚠ 口径提醒：M9′ 的「改善阈值 −10pp」是按熟练玩家基线设计的；新手局的低 M9′ 来自规划失误驱动的危机，**不构成「空转已治好」的证据**（假改善判据 M10/M11/M12 同样不适用此类样本）。

## 6. 事件分析：两局断粮危机与自救（恢复环路对新手同样有效）

**G1（tick 269~502 长期压力）**：eatery 2→5 激进扩张 → tick 270 食归零 → 户 22→14 迁出 → 但玩家持续建房（容量 22→38）+ 磨坊 3→12 爆发 → 农田 3→10、粮仓 1→7 → 食回 243 通关。特点：**危机与爬升并行**（繁荣度全程未回落，靠建房对冲）。
**G2（tick 161~180 + 205~332 两段）**：eatery 扩张 → 食归零（户 12→10）→ 随后**磨坊过建**（mill 4→8→13→17）而农田仅 4 → 粮荒持续 127 tick（磨坊集体空转等粮）→ 农田补到 16 后食回 212 → 311 tick 通关后继续建杂货摊×2 玩到 330。特点：**连锁误判**（把「食不够」误读为「磨坊不够」），是新手对产业链理解的典型弯路，但均在设计容错内自愈。

两局共同验证：**断链警示 → 玩家响应 → 自愈**环路对零经验玩家有效，无弃局、无死锁。
